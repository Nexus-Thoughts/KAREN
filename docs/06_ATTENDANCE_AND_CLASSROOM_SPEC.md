# 06 — Attendance and Classroom Specification

## Rule
Campus presence != classroom presence != attendance.

## Class lifecycle
SCHEDULED -> OPEN -> VERIFICATION -> ATTENDANCE -> CLOSED

## Attendance statuses
PRESENT, ABSENT, LATE, EXCUSED.

## Manual changes
Authorized users may correct attendance. Every correction records:
- actor;
- old value;
- new value;
- timestamp;
- reason.

## Reports
Student, section, subject/session and department views with date-range filtering.

## Automatic attendance
Do not mark attendance merely because GPS indicates the student is inside a classroom radius.
