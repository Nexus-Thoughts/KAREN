# 19 — Definition of Done

## Product
Requirement implemented and acceptance criteria pass.

## Backend
API contract, validation, authorization, tests and audit behavior complete.

## Database
Schema, indexes, constraints and migrations complete.

## AI
Tool permissions, authoritative retrieval, error handling and audit complete.

## Geospatial
PostGIS logic tested for radius, polygon membership, accuracy, state transitions and deduplication.

## UI
The KAREN UI is an exact reuse/extension of the IRIS UI implementation:
- same shell;
- same components;
- same visual behavior;
- same responsive behavior;
- no unrelated redesign.

## Final gate
Do not call a module complete if it works functionally but visually deviates from the IRIS UI requirement.
