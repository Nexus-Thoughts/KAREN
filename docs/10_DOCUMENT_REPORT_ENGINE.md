# 10 — Document and Report Engine

## Lifecycle
REQUESTED -> AUTHORIZED -> DATA_FETCHED -> VALIDATED -> RENDERED -> STORED -> DELIVERED

## Outputs
PDF, DOCX, CSV, JSON, XLSX where required.

## Reports
Attendance, section/class, subject/session, department, campus entry/exit, geofence, notification, audit and administrative reports.

## Rule
The LLM never invents report rows. It requests data from authoritative services; the report engine renders the result.

Generated artifacts inherit user authorization scope.
