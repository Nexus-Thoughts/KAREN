# 09 — AI Tools and Agents

Every tool requires:
- input schema;
- permission;
- resource scope;
- validation;
- structured output;
- audit behavior;
- failure behavior.

Initial tools:
- get_current_user
- get_student_profile
- get_student_attendance
- get_class_attendance
- get_department_attendance
- get_timetable
- get_class_sessions
- get_student_geofence_status
- get_student_exit_events
- search_knowledge
- get_document
- generate_report
- generate_document
- get_notifications

Never expose arbitrary SQL or undocumented tools to the agent.
